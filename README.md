# Atividades-PYTHON
# Exercícios de Python

Repositório destinado às resoluções dos exercícios de Python, com foco no desenvolvimento de lógica de programação e, posteriormente, conceitos utilizados no desenvolvimento backend.

## Objetivo

Praticar Python por meio de exercícios progressivos, começando pelos fundamentos da linguagem e avançando para estruturas e conceitos utilizados em aplicações backend.

## Conteúdos

### Nível 1 — Lógica básica

Exercícios focados nos fundamentos da programação:

1. Par ou ímpar
2. Maior de dois números
3. Média de três notas
4. Contagem de 1 até N
5. Tabuada

Conceitos praticados:

* `input()`
* `print()`
* Variáveis
* `int`
* Operadores matemáticos
* Operadores de comparação
* `if`, `elif` e `else`
* `for`
* `while`

### Nível 2 — Loops e listas

6. Somatório
7. Maior e menor número
8. Lista de nomes
9. Contador de vogais
10. Inversão de texto

Conceitos praticados:

* Listas
* Loops
* `for`
* `while`
* Operador `in`
* Strings
* Manipulação de dados

### Nível 3 — Funções

11. Calculadora
12. Verificador de senha
13. Palíndromo
14. Número primo

Conceitos praticados:

* Funções
* Parâmetros
* Argumentos
* `return`
* Validação de dados
* Reutilização de código

### Nível 4 — Dicionários

15. Cadastro de usuários
16. Sistema de estoque

Conceitos praticados:

* Dicionários
* Estruturas de dados
* CRUD básico
* Organização de informações
* Funções para manipulação de dados

### Nível 5 — Conceitos de Backend

17. Sistema de login
18. API fake
19. CRUD completo
20. Sistema de usuários

Conceitos praticados:

* CRUD
* Organização de projetos
* Separação de responsabilidades
* Simulação de APIs
* POO
* Tratamento de erros
* Módulos
* SQLite
* Ambiente virtual com `venv`
